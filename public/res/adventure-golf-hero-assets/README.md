# Adventure Golf Hero Assets

Diese Assets sind für den Hero-Bereich der Marketing-Webseite gedacht.

## Dateien

- `phone-home-overview.png` — erstes iPhone Mockup / Start- oder Übersichts-Screen
- `phone-scorecard-sponsor.png` — zweites iPhone Mockup / Scorecard mit Beispielwerbung
- `hero-background-blob.svg` — weiche organische Hintergrundform hinter den Phones
- `dot-pattern.svg` — dezentes Punktmuster für Tiefe im Hero
- `icon-flag.svg` — Icon für Floating Card „Branding deiner Anlage“
- `icon-share.svg` — Icon für Floating Card „Scorecards teilen“
- `icon-star.svg` — Icon für Floating Card „Sponsoren integrierbar“

## Empfohlene Platzierung

Lege die Dateien z. B. ab unter:

`public/assets/adventure-golf/hero/`

Dann im Code referenzieren als:

`/assets/adventure-golf/hero/phone-home-overview.png`
`/assets/adventure-golf/hero/phone-scorecard-sponsor.png`
`/assets/adventure-golf/hero/hero-background-blob.svg`

## Layout-Idee

- `phone-home-overview.png` links/vorne, leicht nach links rotiert
- `phone-scorecard-sponsor.png` rechts/vorne, etwas größer und leicht nach rechts rotiert
- `hero-background-blob.svg` absolut dahinter
- Floating Cards um die Phones herum
